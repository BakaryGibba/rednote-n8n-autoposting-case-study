# Assets

This folder is reserved for safe portfolio assets such as exported diagrams, cover images, or sanitized presentation graphics.

## Allowed Assets

- Exported Mermaid diagrams.
- Sanitized screenshots.
- Portfolio cover graphics.
- Demo-only workflow illustrations.

## Disallowed Assets

- `.env` files, tokens, credentials, or n8n credential exports.
- Browser profiles, cookies, or session data.
- Downloaded real videos/images.
- Runtime artifacts containing private platform data.
- Raw source code copied from the implementation repository.
